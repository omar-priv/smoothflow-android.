# Final QA Report

Include:
- Status: PASS / PASS WITH WARNINGS / FAIL / BLOCKED
- Detected languages/frameworks
- Checks actually executed and results
- Confirmed defects and fixes with file paths
- Warnings and skipped checks with reasons
- Important user journeys and edge cases not covered
- External services/devices/integrations not verified
- QA branch and report location

A green pipeline means only that executed checks passed. It is not proof of zero bugs.
